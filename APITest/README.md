# Teste da Coleção no Postman

Este repositório contém a coleção de testes para ser utilizada no Postman. Para testar a coleção, siga as etapas abaixo:

## Como testar

1. Acesse a coleção diretamente no Postman através do seguinte link:

   [Acesse a Coleção no Postman](https://helpers-3389.postman.co/workspace/Helpers-Workspace~b4757d8b-4faf-440e-88ac-1d137196dc0b/collection/39725375-4bb67690-ecad-464e-825d-5867473c365a?action=share&creator=39725375)

2. Clique na coleção e comece a executar os testes.
